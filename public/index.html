앱 실행 방식: 확인 중

설치형 앱으로 실행해도 기기 확인이 끝난 것은 아닙니다. 기기 승인은 서버가 따로 확인합니다.

로그인

접속 계정:
강사 공지 자원 ID: notice-01
정적 data.json 파일의 가상 메모는 서버 저장소로 이전되었습니다. 이전 공개 커밋 이력 및 이전 배포 이력은 지워지지 않고 남아 있으므로 과거 노출은 완전히 해소되지 않았습니다. 현재는 로그인 전 자료 API 접근이 차단되어 메모가 표시되지 않습니다.

기기 승인

이 기기: 승인 전 기기 ID: -

승인 전에는 메모를 불러오지 않습니다. 버튼은 승인 요청만 보내고, 승인 여부는 서버 응답으로 정해집니다.

기기 키는 이 탭의 메모리에서만 쓰고 꺼낼 수 없게 만듭니다. 브라우저 저장소에 넣지 않으므로 새로고침하거나 탭을 닫으면 다시 로그인하고 승인해야 합니다.
